# Operator reference-data loading

Run the loader only with an approved input file and a direct database connection supplied through the process environment. The command is `python seed/load_reference_data.py <file.json>`.

The loader is not exposed through HTTP or browser navigation. Its database writes require the separately authorised operator connection. Preserve the input, its sources, retrieval dates and import receipt for review. Do not promote unsourced indicators or office-holder claims to published data.

Source validation and the final register format are owned by Batch 4. No published reference catalogue is claimed complete at this checkpoint.
