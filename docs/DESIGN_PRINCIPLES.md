# Design Principles

1. **One question per screen.** Task first, data second.
2. **Words first, then pictures.** Every chart has a plain-language sentence above it and a table equivalent below it.
3. **Colour never works alone.** Status is always colour + shape + word.
4. **Motion explains; it never decorates.** No animation on data-entry fields. At most one ambient animation per screen.
5. **Big, forgiving, reversible.** 44 px minimum targets (56 px in the field app), Undo instead of "Are you sure?", autosave everywhere.
6. **The map is the memory.** Anything with a place is shown on the Atlas; people remember where things are.
7. **Respect the government register.** Calm, authoritative, no neon, no gimmicks. Distinctive through typography, paper texture, the Wheel and the Atlas.
